# FitMotion AI - sua 5 van de nguoi dung bao cao (2026-09-04)

1. Camera / AI latency
- YOLOv8 Pose infer o `imgsz=416` thay vi day full preview 960x540 vao model.
- Tu dong dung CUDA + FP16 neu PyTorch nhan GPU; van fallback CPU an toan.
- Camera preview van giu do phan giai cu.

2. Squat + mo hinh 3D
- Tao `static/uploads/references/squat-glb-reference-auto.json` truc tiep tu GLB Squat Mixamo hien co.
- Core 4 exercises co bundled reference fallback, khong phu thuoc database cu co cot/path moi hay khong.
- Squat khi co 3D reference se dung trajectory similarity (DTW) cho depth/rhythm; khong danh rot chi vi mot knee-angle cutoff don le.
- YOLOv8 Pose la deep-learning pose detector cho tat ca bai. Pose phase classifier rieng chi bat khi co checkpoint `.pth` da train + test accuracy >= gate. ZIP hien tai khong co checkpoint `.pth`, nen khong duoc phep noi la phase classifier dang hoat dong.

3. Analytics truc quan
- Them success ring va bieu do cot tuong tac 14 ngay / 8 tuan / 6 thang.
- Backend tong hop success rate (good_rep / total_rep) va quality score theo tung moc thoi gian.
- Trang Phan tich van giu lich su session de audit, nhung phan so sanh chinh chuyen sang do thi.

4. Canh bao nga/ngat sau khi them level
- Xoa hard-code timer 2/4/6 phut bi trung voi `max_session_seconds` cua policy cap do.
- AI/emergency khong bi dung som do timer an.
- Runtime reset khong giu stale emergency/pause state sang phien moi.
- Da chay test safety/reference lien quan: 16 pass.

5. Tach phien theo lan tap
- Ket thuc/dung phien reset `session_started_at`, `last_rep_at`, idle/elapsed, pause/emergency va target runtime.
- Finish khong preserve target/timer cua phien cu.
- Draft bi xoa khi finish/stop nhu truoc; phien moi khong lay dong ho cua level truoc.
